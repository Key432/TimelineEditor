# Phase L0：レベルアップ基盤・データ互換性

優先度：P0

状態：完了（DB・JSON・CSVの基準版v1、旧形式移行、共通参照、Feature Flag、保持上限、互換性テスト基盤）

## 目的

大規模な日付モデル変更、エンティティ参照、履歴、自動保存を、現行データとの互換性を保って安全に実装できる基盤を整える。

## 実装

- 現行DBスキーマとJSON・CSV形式を基準バージョンとして固定
- JSON・CSVへ明示的なスキーマバージョンを付与
- バージョン別インポートマイグレーション機構
- タイムラインアイテムとイベントアイテムの共通参照型
- 削除済み・権限外エンティティ参照を安全に扱う共通処理
- Feature Flag基盤
- 履歴、ゴミ箱、公開複製データの保持上限を各機能で強制できる共通方針
- 後続Phaseのマイグレーション、インポート、参照解決を検証するテスト基盤

## 完了条件

- 現行データを失わず後続マイグレーションを適用できる
- 旧スキーマのJSON・CSVを新スキーマへ安全に移行できる
- 全検証成功
