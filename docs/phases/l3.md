# Phase L3：詳細・編集UI統合と書体切り替え

優先度：P0

状態：完了（同一URLの閲覧／編集切り替え、閲覧・編集共通の通常幅／ワイド／最大化、未保存変更の破棄確認、両エンティティで共通の本文フォーム、通常詳細／URL連動オーバーレイの共通編集シェル、パンくず行とモーダル右上の詳細オプション、ページごとにローカル保存する表示幅・書体）

## 目的

詳細閲覧と編集を同一画面内で完結させる。

## 実装

- 詳細ページと編集ページを共通シェルへ統合
- 同一URLで閲覧・編集モードを切り替え
- URL連動オーバーレイ内でも同じ編集UIを利用
- 別編集ページへの移動を不要にする
- 閲覧・編集で共通する通常幅、ワイド、最大化
- タイムライン、検索結果、スクロール位置を維持
- タイムラインアイテムとイベントアイテムの共通フォーム部品化
- 未保存変更の破棄・明示保存
- タイムラインアイテム・イベントアイテムの通常詳細ページ、URL連動オーバーレイ、公開詳細ページでゴシック体／明朝体を切り替え
- 表示幅と書体設定は詳細ページごとにブラウザへローカル保存する。別ページとは共有せず、プロジェクトデータやSupabaseへは保存しない
- 日本語のシステムフォントスタックを使用し、外部Webフォントやフォントファイルを保存しない
- 書体切り替えをキーボード操作・読み上げ可能にし、選択状態を色だけに依存させない
- 左右の余白、書体、編集モードを単一の詳細オプションへまとめ、通常ページではパンくずリストと同じ行に配置する
- URL連動オーバーレイでは詳細オプション、全画面化、閉じるアイコンを右上の同じ行へ固定し、モーダル外枠と本文を表示幅に合わせて滑らかに拡縮する

## テスト

- 共通詳細シェルの閲覧／編集モード切り替え
- 通常詳細ページとURL連動オーバーレイのフォーム共通化
- ゴシック体／明朝体と表示幅のページごとの保存、同じページでの復元、別ページとの分離
- 公開詳細ページでの書体切り替えとキーボード操作
- 詳細オプションの集約、閲覧・編集共通の3段階幅、URL連動オーバーレイ外枠と本文の滑らかな拡縮

## 完了条件

- 詳細から画面遷移せず編集できる
- 通常ページとオーバーレイで編集構造が共通化される
- 全検証成功
