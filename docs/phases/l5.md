# Phase L5：安全なMarkdown本文

優先度：P0

状態：完了（安全な許可要素レンダリング、GFM表・打ち消し線、5種コールアウト、編集／プレビュー切り替え）

## 目的

タイムラインアイテムとイベントアイテムの本文を安全なMarkdownとして編集・表示する。

## 対応

- 見出し、太字、斜体、打ち消し線
- インラインコード、コードブロック
- 箇条書き、番号付きリスト
- 引用、水平線
- 表
- 外部リンク
- NOTE、TIP、IMPORTANT、WARNING、CAUTION等のコールアウト
- 編集／プレビュー切り替え
- 編集内容を反映したプレビュー
- 本文、編集欄、プレビュー欄は出典・参考文献欄と同じ背景、余白、本文文字サイズを使用する

## 非対応

- Markdown画像
- ファイル添付
- iframe、video、audio、SVG埋め込み
- raw HTML
- script、style
- JavaScript URL、data URL

## 安全性・容量

- Markdown原文だけを保存し、レンダリング済みHTMLは保存しない
- raw HTMLを解釈しない
- AST変換後に許可要素だけを描画
- 外部リンクのプロトコルを制限
- 検索インデックスには装飾を除いた必要最小限のテキストを使用

## 完了条件

- 編集内容がプレビューへ反映される
- HTML直書きや外部埋め込みを実行しない
- 全検証成功
