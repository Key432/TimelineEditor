# Phase L8：完全自動保存

優先度：P0

状態：完了（IndexedDB下書き、復元、保存状態、複数タブ競合検出、明示保存時の楽観的ロック）

## 依存

- Phase L3
- Phase L4
- Phase L5
- Phase L6

## 実装

- 入力停止後、IndexedDBへ下書きをデバウンス保存
- フォーカス移動時、IndexedDBへ下書きを即時保存
- ローカル保存中の追加変更を次キューへ送る
- 同一内容のローカル重複保存防止
- 下書き保存済み、保存中、未保存、失敗、オフライン、再試行中の表示
- 「変更を保存」によるDB確定時、`updated_at`を更新バージョンとして使う楽観的ロック
- BroadcastChannelによる複数タブのローカル下書き競合検出
- IndexedDBへの未確定下書き保存
- ブラウザ再起動後の復元
- 「変更を保存」によるDB保存成功後のローカル下書き削除

## 容量最適化

- ローカル自動保存ではDBスナップショットと履歴を作らない
- 履歴は「変更を保存」による明示保存単位へまとめる
- 未確定下書きはSupabaseではなくIndexedDBへ保存
- 同一内容はIndexedDBへ重複保存しない

## 完了条件

- 通常編集の下書きが保存ボタンなしでローカルへ保全される
- オフラインまたは通信失敗時にも入力内容を失わない
- 入力頻度によってDB更新と履歴が増加しない
- DB更新は「変更を保存」の押下時に限られる
- 全検証成功
