# Phase L8：完全自動保存

優先度：P0

## 依存

- Phase L3
- Phase L4
- Phase L5
- Phase L6

## 実装

- 入力停止後のデバウンス保存
- フォーカス移動時の即時保存
- 保存中の追加変更を次キューへ送る
- 同一内容の重複送信防止
- 保存済み、保存中、未保存、失敗、オフライン、再試行中の表示
- 更新バージョンによる楽観的ロック
- 複数タブ競合の検出
- IndexedDBへの未送信下書き
- ブラウザ再起動後の復元
- DB保存成功後のローカル下書き削除

## 容量最適化

- 自動保存ごとに完全スナップショットを作らない
- 履歴はPhase L4の統合単位へまとめる
- 未送信下書きはSupabaseではなくIndexedDBへ保存
- 同一内容は更新・履歴作成しない

## 完了条件

- 通常編集で保存ボタンを不要にできる
- 通信失敗時にも入力内容を失わない
- 履歴が入力頻度に比例して無制限増加しない
- 全検証成功
