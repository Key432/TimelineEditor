# Phase L13：データ品質チェック・重複統合

優先度：P1

## 品質チェック

- 内部リンク切れ
- 削除済み参照
- 親を持たないイベント
- 全親の期間外にあるイベント
- 出典、本文、必須カスタムフィールドの不足
- 不正な外部URL
- 未使用タグ・種別
- 孤立した関係
- Markdown記法上の問題
- 公開中だが未完成の項目

## 重複検出

- 正規化タイトル
- 別名
- 日付
- 種別
- 親
- 外部URL
- 類似文字列

## 統合

- イベント、タグ、内部リンク、関係、出典、カスタムフィールド、複数親を統合
- 削除側IDへの参照を存続側IDへ変換
- 統合前のプレビューとUndo

## 容量最適化

- 類似度計算結果を恒久保存しない
- 診断結果はオンデマンド生成または短時間キャッシュ
- 大量の重複候補を履歴として保存しない

## 完了条件

- データ不整合を一覧から修正できる
- 重複アイテムを参照関係ごと統合できる
- 全検証成功
