# Phase L18：プロジェクト横断比較

優先度：P2

## 実装

- 複数プロジェクトを共通時間軸で表示
- 所有プロジェクトと閲覧可能な公開プロジェクト
- 共通パン、ズーム、期間強調
- プロジェクト単位の表示・非表示
- タグ、種別、イベント種別フィルター
- 詳細から比較状態へ復帰
- 比較画面は閲覧専用とし、編集機能を提供しない
- 比較条件は保存済みビューとして保存可能

## 容量最適化

- 比較用データを複製保存しない
- プロジェクトごとに段階取得
- 表示年代付近だけを取得するAPIを検討
- 比較ビューは設定JSONだけを保存

## 完了条件

- 複数年表を同じ年代で比較できる
- 全検証成功
