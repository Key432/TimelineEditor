# Phase L18：タイムライン内プロジェクト比較

優先度：P2

## 実装

- `/timeline` の「他プロジェクトと比較」から所有プロジェクトと閲覧可能な公開プロジェクトを検索・複数選択する
- 基準プロジェクトを含むタイムラインを上下へ分割表示する
- 1〜4画面は表示領域を等分し、5画面目以降は1画面あたり25%を維持して縦スクロールする
- 比較中は全画面を閲覧専用・コンパクト表示へ固定する
- 比較対象の選択・削除・ドラッグ並べ替えを比較モーダルへ集約する
- 年代ヘッダーと操作ツールバーは基準プロジェクトだけに表示し、下段の選択プルダウンと案内フッターを省く
- タイムライン間の余白、角丸、重複枠を省き、境界線だけで連続表示する
- 共通の年代範囲とZustandストアで横パン、ズーム、ホバー日付線を同期する
- 比較対象IDは現在の `/timeline` URLの `compare` クエリへ保持する

## データと容量

- 比較専用テーブルと保存済み比較ビューは設けない
- タイムライン項目・イベント・描画結果を複製保存しない
- 比較対象はプロジェクトごとにAPI取得し、RLSで所有または公開範囲に限定する

## 完了条件

- 3件以上の比較先を同時に表示できる
- 5画面以上で縦スクロールできる
- パン、ズーム、ホバー線が全画面で同期する
- 比較モーダルでポインターとキーボードの両方から表示順を変更できる
- 年代ヘッダーと操作ツールバーが最上段にだけ表示される
- 比較中にアイテムを追加できない
- 全検証成功
