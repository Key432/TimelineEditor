# Phase L9：タグ・イベント種別・カスタムフィールド

優先度：P1

状態：完了

## タグ

- タイムラインアイテムとイベントアイテム共通のタグマスタ
- 多対多関連
- 名称変更、統合、未使用タグ削除
- タグによる検索・AND／ORフィルター
- 任意色と説明

## イベント種別

- 出版、受賞、移住、就任、展覧会、公演等
- イベント専用種別マスタを基本案とする
- マーカー形状・アイコンによる区別
- 色だけに依存しない
- 円、四角、ひし形、三角、星、六角形を図形プレビューから選択する
- 同種別クラスターは種別の形状・色、異種別クラスターは灰色の円を使う

## カスタムフィールド

- プロジェクトまたはタイムライン種別ごとに定義
- 文字列、複数行、数値、真偽値、単一選択、複数選択、URL、歴史日付、他アイテム参照
- テーブルビューで列表示
- 必須・任意設定
- 検索・統計へ利用可能な型情報

## UI

- タグはNotionのマルチセレクトを参考に、選択済みチップと検索・作成候補を同じ入力欄へ表示する
- 候補の「…」から名称、色、説明、未使用削除を操作する
- タグ、イベント種別、タイムライン種別、親タイムラインアイテムの候補は、入力欄以外をクリックしたときに閉じる。候補欄には専用の「閉じる」ボタンを置かない
- イベント種別とタイムライン種別は入力欄から検索・選択・新規作成でき、各候補の「…」から色と図形またはアイコンを視覚的に変更できる
- 種別候補の「…」で設定を開いている間も候補一覧は展開したままにし、設定変更は保存ボタンを待たず即時反映する
- タイムライン種別の色・アイコンとイベント種別の色・マーカー形状は、変更後に関連する項目／イベント一覧キャッシュも更新し、タイムラインフィールドへページ再読込なしで反映する
- タイムライン種別のアイコンは文字列として保存し、クライアントで対応するSVGへ変換する。種別グループ見出しには指定色のアイコンを表示する
- 親タイムラインアイテムは検索・選択候補を表示するが、候補の設定変更は提供しない
- 「種別・タグ・カスタムフィールド」パネルへタイムライン種別、イベント種別、タグ、カスタムフィールド管理を統合する
- 統合パネルは入力欄を自動フォーカスせず、タイムライン種別、イベント種別、タグの統合、カスタムフィールドの順で表示する
- タイムラインアイテムとイベントアイテムの新規作成・編集フォームの双方でカスタムフィールド値を入力できる

## データ互換性

- DB互換性基準をv4へ更新する
- JSON／CSV ZIP v4で分類マスタ、関連、型付き値、エンティティ参照をID再マップして往復する
- v0〜v3はタグ・イベント種別・カスタムフィールドなしとしてv4へ自動移行する

## 容量最適化

- タグ名を各アイテムへ配列複製せず関連テーブルで管理
- カスタムフィールド定義と値を分離
- 空値を保存しない
- JSONBを使う場合も、検索対象すべてへ無条件の汎用GINインデックスを作らない
- ローカルPostgresで100タグ、20イベント種別、1,000アイテムタグ関連、10,000イベントタグ関連、20定義、10,000値を一時投入した結果、対象6テーブルとインデックスは344,064 bytesから6,266,880 bytesへ増加（差分5,922,816 bytes、約5.65 MiB）

## 後続フェーズとの境界

- カスタムフィールド値は型付きで保存・取得できる状態までをL9で実装する
- テーブル列としての表示はテーブルビュー本体を実装するPhase L11で接続する

## 完了条件

- 両エンティティへ自由タグを付与できる
- イベントを種別で分類できる
- 用途固有の属性を追加できる
- 全検証成功
