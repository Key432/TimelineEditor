# Phase L9：タグ・イベント種別・カスタムフィールド

優先度：P1

## タグ

- タイムラインアイテムとイベントアイテム共通のタグマスタ
- 多対多関連
- 名称変更、統合、未使用タグ削除
- タグによる検索・AND／ORフィルター
- 任意色と説明

## イベント種別

- 出版、受賞、移住、就任、展覧会、公演等
- イベント専用種別マスタを基本案とする
- マーカー形状・アイコンによる区別
- 色だけに依存しない

## カスタムフィールド

- プロジェクトまたは対象種別ごとに定義
- 文字列、複数行、数値、真偽値、単一選択、複数選択、URL、歴史日付、他アイテム参照
- テーブルビューで列表示
- 必須・任意設定
- 検索・統計へ利用可能な型情報

## 容量最適化

- タグ名を各アイテムへ配列複製せず関連テーブルで管理
- カスタムフィールド定義と値を分離
- 空値を保存しない
- JSONBを使う場合も、検索対象すべてへ無条件の汎用GINインデックスを作らない

## 完了条件

- 両エンティティへ自由タグを付与できる
- イベントを種別で分類できる
- 用途固有の属性を追加できる
- 全検証成功
