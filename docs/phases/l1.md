# Phase L1：歴史日付モデルの拡張

優先度：P0

状態：完了（紀元前・年／年代／世紀精度、手動日付表記、概算UI、正規化範囲、連続時間軸、JSON／CSV v2移行）

## 目的

紀元前、年代、世紀を検索・並べ替え・描画可能な歴史日付として実装する。

## 対応

- 西暦年月日
- 紀元前年月日
- 年単位
- 年代単位
- 世紀単位
- 曖昧な年・年代・世紀
- 開始と終了で異なる精度
- 原資料上の日付表記
- 暦法情報を保持できる拡張余地

## 規則

- 利用者向け表示に西暦0年を使わない
- 紀元前1年と西暦1年を連続して計算する
- 19世紀は1801年から1900年
- 1860年代は1860年から1869年
- 紀元前5世紀は紀元前500年から紀元前401年
- 年代・世紀は内部的に最小境界と最大境界を持つ
- 日付精度と「おおよそ」を別属性として扱う

## UI・検索

- 紀元後／紀元前切り替え
- 日付精度選択
- 年、年代、世紀に応じた入力UI
- 年月日と同じ行の「おおよそ」入力、全幅の手動日付表記入力
- 概算日付を「日付 頃」として表示
- 表記プレビュー
- 紀元前から西暦へまたがるパン、ズーム、fit-range
- 紀元前を含む時間軸ラベル
- 正規化範囲による検索、フィルター、並べ替え

## 入出力

- JSON・CSVへ時代、精度、年代、世紀、原表記を追加
- 現行の西暦データから自動移行

## 完了条件

- 紀元前から現代まで連続した時間軸として扱える
- 年、年代、世紀が検索・描画へ反映される
- 全検証成功
