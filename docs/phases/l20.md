# Phase L20：ログイン前ローカルモード・PWA

優先度：P2

## 目的

未ログインでもブラウザ内で年表を作成し、Supabase容量を消費せず利用できるようにする。

## 実装

- IndexedDB保存
- ローカル専用ID
- IndexedDBスキーママイグレーション
- 完全自動保存
- ローカル全文検索
- JSON・CSV入出力
- ブラウザ容量不足警告
- PWAインストール
- オフライン閲覧・編集
- ログイン後のプロジェクト選択取込
- ID、内部リンク、複数親、関係の一括変換
- 取込成功までローカルデータを削除しない

## 容量方針

- ローカルプロジェクトはSupabaseへ自動同期しない
- 利用者が明示的に取り込んだ場合だけクラウド容量を消費する
- 大容量プロジェクトは取込前に概算容量を表示する

## 完了条件

- 未ログインで年表を作成・保存できる
- ログイン後に安全にクラウドへ移行できる
- 全検証成功
