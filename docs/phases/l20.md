# Phase L20：ログイン前ローカルモード

状態：完了（ルートページでのゲスト作成、IndexedDB保存、全文検索、JSON・CSV入出力、クラウド選択取込対応済み。PWA化はユーザー判断により対象外）

優先度：P2

## 目的

未ログインでもブラウザ内で年表を作成し、Supabase容量を消費せず利用できるようにする。

## 実装

- IndexedDB保存
- ローカル専用ID
- IndexedDBスキーママイグレーション
- 完全自動保存
- ローカル全文検索
- JSON・CSV入出力
- ブラウザ容量不足警告
- 未ログインのルートページを既存タイムラインと同系統のレイアウトにし、右上のログインボタンから `/login` へ移動
- 読み込み済みページではネットワーク切断中もIndexedDBへの編集保存を継続
- ログイン後のプロジェクト選択取込
- ID、内部リンク、複数親、関係の一括変換
- 取込成功までローカルデータを削除しない
- 取込成功後も安全のためローカル原本を自動削除しない

## 容量方針

- ローカルプロジェクトはSupabaseへ自動同期しない
- 利用者が明示的に取り込んだ場合だけクラウド容量を消費する
- 大容量プロジェクトは取込前に概算容量を表示する

## 完了条件

- 未ログインで年表を作成・保存できる
- ログイン後に安全にクラウドへ移行できる
- 全検証成功

## 実装判断

- 通知等を持たない本アプリではインストール可能化の利点が小さいため、manifest、Service Worker、インストールUIを含むPWA化は実装しない。
- Supabase匿名ユーザーは作成せず、未ログインデータは `chronology-studio-local` IndexedDBだけへ保存する。
- ローカル保存形式はJSONバックアップの現行スキーマと揃え、既存のトランザクション取込でID、内部リンク、イベント複数親、意味的関係を一括再採番する。
- DBスキーマ、RLS、Supabase容量に変更はない。
- 1,000タイムラインアイテム・10,000イベントのローカルデータを25MiB未満で直列化でき、末尾イベントを含む全文検索が成功する単体試験を追加した。
