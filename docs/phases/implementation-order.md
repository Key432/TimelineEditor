├─ プロジェクト横断比較

├─ 変更履歴・ゴミ箱

# 初期対象外

- Web版への画像・ファイル添付
- Web版Markdownへの画像埋め込み
- iframeや外部ページ埋め込み
- raw HTML
- リアルタイム共同編集
- Web版とWindows版の自動同期
- Windows版のログイン
- Windows版からの公開URL発行
- AIによる自動関係抽出・自動本文生成
- 複数利用者間のコメント・レビュー
- Web版での無制限履歴・無制限スナップショット
- Web版での生成PDF・画像の恒久保存
