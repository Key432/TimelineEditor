# Phase L14：意味的関係とタイムライン上の矢印

優先度：P1

## 実装

- influence、reference、collaboration、teacher、opposition、succession、other等
- 方向あり・方向なし
- タイムラインアイテム／イベントの全組み合わせ
- 関係種別、方向、注記
- 詳細ページでの追加・編集・削除
- 選択中アイテムの直接関係だけを表示する既定モード
- 表示範囲内の全関係表示オプション
- 線・矢印のホバー、クリック
- コンパクトレーン・クラスター対応

## 表示方針

- 全関係線の常時表示を既定にしない
- 通常時は非表示または選択対象の直接関係だけ表示
- 大量線表示はネットワークビューへ分離する

## 完了条件

- アイテム間の意味的関係を登録・表示できる
- 大量の線で通常タイムラインを破壊しない
- 全検証成功
