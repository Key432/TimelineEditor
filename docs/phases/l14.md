# Phase L14：意味的関係とタイムライン上の矢印

優先度：P1

状態：完了

## 実装

- 日本語の既定種別（影響、参照、協働、師弟、対立、継承、その他）と自由入力
- 方向あり・方向なし
- タイムラインアイテム／イベントの全組み合わせ
- 関係種別、方向、注記
- 詳細ページでの追加・編集・削除
- 選択中アイテムの直接関係だけを表示する既定モード
- 表示範囲内の全関係表示オプション
- 線・矢印のホバー、クリック
- コンパクトレーン・クラスター対応
- 単線／二重線と始点／終点矢印の独立切り替え
- 画面水平・垂直の直角線、項目より前面かつ行表示の固定列・グループ見出しより背面の重なり順
- 種別グループをまたぐ関係を、折りたたみ見出しの下へ接続
- 「分類・関係」パネルへの管理UI統合
- JSON／CSV ZIPスキーマv7、選択行CSV、複製・統合・Undoへの関係スタイル連携

## 表示方針

- 全関係線の常時表示を既定にしない
- 通常時は非表示または選択対象の直接関係だけ表示
- 大量線表示はネットワークビューへ分離する

## 完了条件

- アイテム間の意味的関係を登録・表示できる
- 大量の線で通常タイムラインを破壊しない
- 全検証成功

## 容量確認

- 1プロジェクトへ意味的関係10,000件を投入するローカルPostgres試験で、テーブル・索引込みの増加量は4,538,368 bytes、投入時間は約287msだった。
- 関係データ以外の派生画像・描画結果・統計スナップショットは保存しない。通常タイムラインは直接関係だけを既定表示し、全件常時描画を避ける。
