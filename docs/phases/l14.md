# Phase L14：意味的関係とタイムライン上の矢印

優先度：P1

状態：完了

## 実装

- 日本語の既定種別（影響、参照、協働、師弟、対立、継承、その他）と自由入力
- 方向あり・方向なし
- タイムラインアイテム／イベントの全組み合わせ
- 関係種別、方向、注記
- 詳細ページのリンク付き閲覧専用一覧と、編集モードでの追加・編集・削除
- タイムラインアイテム／イベントの新規追加パネルでの関係同時登録
- 半透明灰色で表示してホバー時に着色する「標準」、常時着色する「すべて表示」、「すべて非表示」の3段階表示
- 線・矢印のホバー、クリック
- コンパクトレーン・クラスター対応
- 単線／二重線と始点／終点矢印の独立切り替え
- 始点から垂直、行間を水平、終点へ垂直に接続する直角線と、項目より前面かつ時間軸ヘッダー・行表示の固定列・編集列・グループ見出し・詳細オーバーレイより背面の重なり順
- コンパクトレーン下部のバー／マーカー中心へ一致する関係アンカー
- 種別グループをまたぐ関係を、折りたたみ見出しの下へ接続
- 「分類・関係」パネルへの管理UI統合
- JSON／CSV ZIPスキーマv7、選択行CSV、複製・統合・Undoへの関係スタイル連携

## 表示方針

- 既定の「標準」は表示範囲の関係線を半透明灰色に抑え、ホバーまたはフォーカス時だけ関係色で強調する
- 利用者はツールバーから「すべて表示」「すべて非表示」へ切り替えられる
- 関係線の確認ポップアップはクリックまたはキーボード操作した線の近くへ表示し、外側クリックで閉じて選択色を解除する
- 大量線表示はネットワークビューへ分離する

## 完了条件

- アイテム間の意味的関係を登録・表示できる
- 大量の線で通常タイムラインを破壊しない
- 全検証成功

## 容量確認

- 1プロジェクトへ意味的関係10,000件を投入するローカルPostgres試験で、テーブル・索引込みの増加量は4,538,368 bytes、投入時間は約287msだった。
- 関係データ以外の派生画像・描画結果・統計スナップショットは保存しない。通常タイムラインは表示年代と仮想化されたアンカーへ描画対象を限定し、着色線の常時表示を避ける。
