# Phase L15：関連ネットワークビュー

優先度：P2

## 実装

- アイテムとイベントをノード表示
- 関係を方向付き／方向なしエッジ表示
- タグ、種別、年代、関係種別フィルター
- 期間強調連携
- ノード検索
- 直接関係・2段階関係の強調
- ノードから詳細を開く
- Force-directedを初期レイアウトとする
- 大規模データの段階展開・クラスタ化

## 容量最適化

- 自動計算したノード位置を原則DBへ保存しない
- 利用者が明示固定した位置だけ保存する余地を残す
- 事前計算済みグラフを大量保存しない

## 完了条件

- 関係データを独立したネットワークとして探索できる
- 全検証成功
