# Phase L15：関連ネットワークビュー

優先度：P2

状態：完了

## 実装

- アイテムとイベントをノード表示
- 関係を方向付き／方向なしエッジ表示
- タグ、種別、年代、関係種別フィルター
- 期間強調連携
- ノード検索
- 直接関係・2段階関係の強調
- ノードから詳細を開く
- Force-directedを初期レイアウトとする
- 大規模データの段階展開・クラスタ化

## 実装判断

- タイムラインとイベントは種別色を添えた角丸四角ノードとして統一する
- エッジはL14の単線／二重線、始点／終点矢印、方向付き／方向なし設定をそのまま描画する
- D3 forceのリンク距離、斥力、矩形外接円の衝突判定で初期配置し、同一ノード間の複数エッジは曲率をずらして重なりを減らす
- マウスホイールはカーソル中心の拡大縮小、余白ドラッグはキャンバス移動、ノードドラッグはその表示中だけの一時配置とする
- タグ、タイムライン種別／イベント種別、年代、関係種別、検索をクライアント側で絞り込む。選択ノードの直接関係と2段階関係を別表示で強調する
- 160ノードを初期上限とし、超過分は種別クラスタへまとめる。クラスタ操作ごとに最大160ノードずつ追加する
- ネットワーク本体はクライアント専用の動的チャンクとして読み込み、準備中はネットワーク専用スケルトンを表示する
- 自動配置・手動移動結果・クラスタ描画結果はDBへ保存せず、現在のアイテム、イベント、意味的関係から都度生成する

## 容量最適化

- 自動計算したノード位置を原則DBへ保存しない
- 利用者が明示固定した位置だけ保存する余地を残す
- 事前計算済みグラフを大量保存しない

## 完了条件

- 関係データを独立したネットワークとして探索できる
- 全検証成功

## 容量確認

- DBマイグレーション、RLS、制約、インデックス、保存データの追加はない
- 1,000ノード入力で初期描画対象が160ノードと残りクラスタに制限されることを単体テストで確認する
