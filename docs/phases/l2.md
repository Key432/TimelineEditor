# Phase L2：閲覧操作・保存済みビュー

優先度：P1

状態：完了（アプリ内最大化／Fullscreen、Esc復帰、垂直年代線と交差強調、丸型アイコンから展開するフロート操作群、初期状態が非表示の期間強調、年代ジャンプ、位置ブックマーク、設定JSONの保存済みビュー。全期間ミニマップは保留）

## 目的

タイムラインの移動、年代把握、表示状態の再利用を改善する。

## 実装

- タイムライン表示領域のアプリ内最大化
- 対応ブラウザでのFullscreen API利用
- Escによる復帰
- マウスポインター位置の垂直年代線
- 垂直線と重なるイベント・クラスターの強調
- ホバーUIまたはフォーカスポップオーバーから詳細を開く操作
- タイムラインフィールド内へ固定し、初期状態を非表示として、表示切替、始点・終点指定、選択期間の着色、期間外のグレーアウトに対応する期間強調
- 全期間ミニマップは実装を保留
- 年代ジャンプ
- 表示位置ブックマーク
- 保存済みビュー

保存済みビューには以下を含める。

- 表示年代
- ズーム・スクロール位置
- フィルター
- タグ条件
- 並び順・グループ
- 行表示／コンパクトレーン
- 背景レイヤー
- 関係線表示
- 表示列

保存済みビューは小さな設定JSONだけを保存し、データ本体を複製しない。

## 完了条件

- 特定年代へ素早く移動・抽出できる
- 複雑な表示状態を再利用できる
- 全検証成功
