# Phase L7：構造化された出典・参考文献

優先度：P1

状態：完了（自由記述互換、資料マスタ、多対多関連、個別ロケータ、引用記法、未設定抽出）

## 目的

共通の資料マスタを持ち、複数アイテムから同じ文献を参照できるようにする。

## 実装

- 従来の自由記述欄を維持し、フォームでは自由記述タブを既定表示する
- 詳細登録は任意のタブとして提供し、自由記述と同時に保存・表示できる
- 資料名、著者、出版社、刊行年、ISBN、URL、参照日、引用キー、注記
- アイテム・イベントとの多対多関連
- ページ番号、章、引用箇所等の個別ロケータ
- 出典から参照中アイテム一覧
- 出典未設定項目の抽出
- Markdown本文中の引用記法
- BibTeX、CSL JSON等の入出力候補
- 将来のZotero連携余地

## 引用記法

- 詳細出典の引用キーが `yamada2024` の場合、本文中の `[@yamada2024]` を資料マスタへのリンクとして表示する
- 引用キーが未登録または当該項目へ関連付けられていない場合は、原文を変更しない
- BibTeX、CSL JSON、Zotero連携は、現行の分離された資料マスタと引用キーから拡張する将来候補とする

## 容量最適化

- 同じ書誌情報を各アイテム本文へ複製しない
- 書誌情報は資料マスタへ一度だけ保存する
- 外部ページ本文や書影は保存しない

## 完了条件

- 同一資料を複数項目から再利用できる
- 引用箇所を項目ごとに指定できる
- 全検証成功
