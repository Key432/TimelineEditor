# Phase L7：構造化された出典・参考文献

優先度：P1

## 目的

共通の資料マスタを持ち、複数アイテムから同じ文献を参照できるようにする。

## 実装

- 資料名、著者、出版社、刊行年、ISBN、URL、参照日、引用キー、注記
- アイテム・イベントとの多対多関連
- ページ番号、章、引用箇所等の個別ロケータ
- 出典から参照中アイテム一覧
- 出典未設定項目の抽出
- Markdown本文中の引用記法
- BibTeX、CSL JSON等の入出力候補
- 将来のZotero連携余地

## 容量最適化

- 同じ書誌情報を各アイテム本文へ複製しない
- 書誌情報は資料マスタへ一度だけ保存する
- 外部ページ本文や書影は保存しない

## 完了条件

- 同一資料を複数項目から再利用できる
- 引用箇所を項目ごとに指定できる
- 全検証成功
