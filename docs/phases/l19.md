# Phase L19：統計情報

優先度：P2

## 集計候補

- アイテム・イベント件数
- 対象種別・イベント種別・タグ別件数
- 年代・世紀別件数
- 存続期間分布
- 曖昧日付・終了状態別件数
- イベントを持たないアイテム
- 複数親イベント
- 関係種別と関係数
- 内部リンク数・リンク切れ
- 本文・出典未入力件数

## 表示

- KPI、棒、折れ線、ヒストグラム、ヒートマップ、集計表
- 期間強調・フィルター連動
- 集計結果から該当項目へ移動
- CSV出力

## 容量最適化

- 統計値は原則オンデマンド計算
- 長期の集計スナップショットを保存しない
- 必要な場合のみ短時間キャッシュ
- 大規模な分析履歴やデータキューブはWindows版限定候補

## 完了条件

- プロジェクトの構成と不足を把握できる
- 全検証成功
