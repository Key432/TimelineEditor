# Phase L19：統計情報

優先度：P2

状態：完了

統計情報は既存の品質分析と同じ「統計・品質チェック」パネルへ統合し、「統計」「品質チェック」のタブで切り替える。独立した統計ページや統計テーブルは設けない。

## 集計候補

- アイテム・イベント件数
- 対象種別・イベント種別・タグ別件数
- 年代・世紀別件数
- 存続期間分布
- 曖昧日付・終了状態別件数
- イベントを持たないアイテム
- 複数親イベント
- 関係種別と関係数
- 内部リンク数・リンク切れ
- 本文・出典未入力件数
- タイムラインアイテム・イベントアイテムの日別作成数（直近1年）

## 表示

- KPI、棒、折れ線、ヒストグラム、ヒートマップ、集計表
- 集計候補に応じてD3.jsの棒グラフ、円グラフ、ヒストグラムを使う
- 日別作成数はGitHubのContributionsと同じ週列×曜日行のヒートマップで表示する
- 期間強調・フィルター連動
- 集計結果から該当項目へ移動
- CSV出力

## 容量最適化

- 統計値は原則オンデマンド計算
- 長期の集計スナップショットを保存しない
- 必要な場合のみ短時間キャッシュ
- 大規模な分析履歴やデータキューブはWindows版限定候補

## 完了条件

- プロジェクトの構成と不足を把握できる
- 全検証成功

## 実装結果

- `GET /api/projects/[projectId]/analysis` が品質診断と統計を同じオンデマンドデータセットから返す
- タイムラインのフィルターと期間強調を集計条件へ反映する
- 棒グラフの集計結果から該当データの詳細へ移動できる
- 表示中の集計をCSVとしてブラウザから出力する
- 統計スナップショット、分析履歴、専用インデックスは追加しない
