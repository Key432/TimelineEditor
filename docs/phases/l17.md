# Phase L17：SVG・PNG・PDF出力

優先度：P1

## 方針

共通の出力描画モデルを作り、SVGを基本としてPDF・PNGへ展開する。

## 実装

- 現在の表示範囲
- 期間強調範囲
- 全項目範囲
- 任意年代範囲
- 行表示／コンパクトレーン
- フィルター、グループ、背景レイヤー、関係線
- タイトル、説明、凡例
- 用紙サイズ、向き、余白
- 1ページ縮小／複数ページ分割
- 日本語フォントとページ境界確認

## 容量最適化

- 生成ファイルをSupabase StorageやDBへ保存しない
- サーバー生成時も一時ファイルとして処理後に削除
- 可能な場合はブラウザ側生成を優先
- 出力履歴はファイル本体ではなく任意の小さな設定だけを保存

## 完了条件

- 編集可能なSVGと印刷可能なPDFを出力できる
- Supabase容量を恒久消費しない
- 全検証成功
