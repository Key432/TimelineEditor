# Phase L17：SVG・PNG・PDF出力

状態：完了

優先度：P1

## 方針

共通の出力描画モデルを作り、SVGを基本としてPDF・PNGへ展開する。

## 実装

- 現在の表示範囲
- 期間強調範囲
- 全項目範囲
- 任意年代範囲
- 行表示／コンパクトレーン
- フィルター、グループ、背景レイヤー、関係線
- タイトル、説明、凡例
- 用紙サイズ、向き、余白
- 1ページ縮小／複数ページ分割
- 日本語フォントとページ境界確認

## 実装結果

- 既存の「インポート／エクスポート」パネルへ表示出力カードを統合した
- 行表示、コンパクト、関連ネットワークを同じSVG描画モデルから出力する
- タイムラインは「全データを出力」「指定期間を出力」に加え、現在の表示範囲と期間強調範囲を選べる
- SVGは編集可能なベクター、PNGは対象領域全体を一枚の画像としてブラウザ内で生成する
- PDFはA4・A3・Letter、縦・横、余白、1ページ縮小、縦幅合わせ、横幅合わせ、オリジナルサイズを選択でき、用紙を超える方向を複数ページへ分割する
- 日本語はブラウザのNoto Sans JP／日本語システムフォントで描画して画像としてPDFへ埋め込み、PDFライブラリ側の日本語フォント欠落を回避する
- 生成ファイルと出力履歴はSupabase、サーバー、一時領域へ保存しない

## 容量最適化

- 生成ファイルをSupabase StorageやDBへ保存しない
- サーバー生成時も一時ファイルとして処理後に削除
- 可能な場合はブラウザ側生成を優先
- 出力履歴はファイル本体ではなく任意の小さな設定だけを保存

## 完了条件

- 編集可能なSVGと印刷可能なPDFを出力できる
- Supabase容量を恒久消費しない
- 全検証成功
