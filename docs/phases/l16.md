# Phase L16：下書きと公開版の分離

優先度：P1

## 目的

編集中の状態を公開ページへ即時反映せず、整合性のある版だけを公開する。

## 実装

- 下書き
- 公開済み
- 未公開変更あり
- 公開前プレビュー
- 変更を公開
- 現行公開版へ戻す
- 公開日時と公開リビジョン

## 容量最適化

- 公開のたびに全世代を複製しない
- 公開表示に必要な列だけを公開用領域へ保持
- Web版では現行公開版を基本とする
- 過去公開版は最大1世代など少数に限定
- 過去版の長期保管はJSONエクスポートまたはWindows版へ委ねる
- 容量不足時は過去公開版保持を無効化できる

## 完了条件

- 編集途中の状態を公開せずに済む
- 公開用データが世代数に比例して無制限増加しない
- 全検証成功
