# Windowsネイティブアプリ系列

優先度：P3

Windows版はWeb版の一機能ではなく独立製品として扱う。Web版のスキーマ、歴史日付、Markdown、内部リンク、タグ、複数親、関係、CSV形式が安定してから開始する。

## Phase W1：設計

- 技術選定
- ローカルDB
- 自動更新
- インストーラー
- データ保存場所
- バックアップ
- Web版との共有パッケージ範囲

## Phase W2：基本版

- ログインなし
- ローカルプロジェクト
- 主要タイムライン機能
- Markdown、内部リンク、タグ、カスタムフィールド
- 複数親、関係、テーブルビュー
- JSON・CSV
- 自動保存

## Phase W3：画像・長期保存

Windows版限定候補：

- 詳細ページへの複数画像
- アプリ管理フォルダへの画像コピー
- サムネイル
- 画像込みZIPバックアップ
- 無制限または大容量の変更履歴
- 長期スナップショット
- 長期の公開相当スナップショット
- 大規模統計キャッシュ

Web互換CSVには画像バイナリを含めず、画像は別マニフェストで管理する。

## Phase W4：互換性検証

- Web版CSVをWindows版へ取込
- Windows版CSVをWeb版へ取込
- 紀元前、世紀、年代
- Markdown、内部リンク、タグ
- カスタムフィールド、複数親、関係、背景レイヤー
- 未対応列の安全な無視
- スキーマバージョン差異警告
