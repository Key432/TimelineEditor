# Phase L10：イベントの複数親対応

優先度：P0

## 目的

1つのイベントを複数の期間型タイムラインアイテムへ紐づけ、それぞれの行・レーンへ表示する。

## データモデル

- `timeline_event_item_links` 関連テーブル
- 主親 `is_primary`
- 親子所属と意味的関係を分離
- 現行 `timeline_item_id` からの安全な移行

## UI・表示

- 複数親検索・選択
- 親ごとの期間外警告
- 各親行への同一イベント表示
- 表示マーカー数とイベント実体数を区別
- 通常ページでは主親をパンくずの既定値にする
- 遷移元親が明確な場合はその親を表示
- クラスタリングとコンパクトレーンへ対応

## 完了条件

- 1イベントを複数親上へ表示できる
- 検索、統計、CSVでイベントを二重計上しない
- 全検証成功
