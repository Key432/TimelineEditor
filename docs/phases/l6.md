# Phase L6：プロジェクト内リンク・別名

優先度：P0

## 目的

Markdown本文から同一プロジェクト内のアイテムを安定IDで参照する。

## 記法

利用者入力は `[[項目名]]` とし、候補選択後に内部的には次の形式へ正規化する。

```md
[[item:UUID|表示名]]
[[event:UUID|表示名]]
```

## 規則

- `[[` 入力時にプロジェクト内候補を表示
- 同名候補には種類、日付、親を表示
- 名称だけでは自動確定しない
- リンク解決は名称ではなくIDで行う
- 名称変更後もリンクを維持
- 削除済みリンクは本文を残し、リンク切れとして表示
- 権限外と不存在を外部利用者から区別できないようにする
- 被参照アイテム削除時に参照元件数を表示
- プロジェクト複製・CSV取込時にIDを変換

## 別名

- 正式名称、原語名、旧名、筆名等を複数登録
- 検索、内部リンク候補、重複検出へ利用
- タイトル変更時に旧名称を別名へ追加できる

## 容量最適化

- 本文内のID参照を別の完全コピーとして保存しない
- 参照逆引きが必要な場合は小さな関連テーブルまたは更新時抽出を使用する
- 本文全文を参照索引へ重複保存しない

## 完了条件

- 名称変更後も内部リンクが維持される
- 同名、削除済み、権限外を安全に扱える
- 全検証成功
