# Phase L12：年代背景レイヤー

優先度：P1

状態：完了（複数背景レイヤー、歴史日付、重複警告、公開・保存済みビュー・JSON／CSV ZIP v6対応）

## 実装

- 時代区分、王朝、政権、文化潮流等の複数レイヤー
- レイヤー単位の表示・非表示
- レイヤー並べ替え
- 背景期間の色、説明、開始・終了
- 紀元前、年代、世紀対応
- 曖昧開始・終了のグラデーション
- 同一レイヤー内の重複警告
- 行表示・コンパクトレーン対応
- 公開ページ対応
- 保存済みビューとの連携

## 実装判断

- レイヤーと期間を正規化テーブルへ分離し、期間は通常のタイムラインアイテムへ複製しない
- 行表示とコンパクトは同じ時間座標の背景描画を共有し、固定情報列を覆わない
- 開始・終了の概算状態は端の透明グラデーションとして描画し、同一レイヤーの重複は保存を妨げず警告する
- レイヤーの既定表示変更だけを現在の表示へ同期し、期間編集時は保存済みビューまたは手動の表示選択を保持する
- JSON／CSV ZIPをv6へ更新し、`background-layers.json` を含める。旧v0〜v5は背景なしとして段階移行する

## DB・RLS

- `20260801085852_phase_l12_background_layers.sql`
- `timeline_background_layers` と `timeline_background_periods` を追加し、プロジェクト／レイヤー削除時は `ON DELETE CASCADE` とする
- 所有者は全操作、他ユーザーと匿名は公開プロジェクトの参照だけを許可するRLSと明示権限を設定する
- 歴史日付の正規化生成列と範囲制約、レイヤー順・期間範囲のB-tree索引を追加する

## 大規模データ試験

- `tests/performance/phase-l12-scale.sql` で20レイヤー・2,000背景期間を一時登録する
- 2026-08-01の測定では113ms、対象2テーブルの物理増加量は737,280 bytes（約720KiB）だった
- 試験は測定値を例外で返してトランザクション全体をロールバックし、試験データを残さない

## 容量最適化

- 背景期間は通常アイテムへ複製しない
- 描画結果を保存しない
- 背景レイヤー用の検索インデックスは必要になるまで追加しない
