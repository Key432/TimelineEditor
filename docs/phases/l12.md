# Phase L12：年代背景レイヤー

優先度：P1

## 実装

- 時代区分、王朝、政権、文化潮流等の複数レイヤー
- レイヤー単位の表示・非表示
- レイヤー並べ替え
- 背景期間の色、説明、開始・終了
- 紀元前、年代、世紀対応
- 曖昧開始・終了のグラデーション
- 同一レイヤー内の重複警告
- 行表示・コンパクトレーン対応
- 公開ページ対応
- 保存済みビューとの連携

## 容量最適化

- 背景期間は通常アイテムへ複製しない
- 描画結果を保存しない
- 背景レイヤー用の検索インデックスは必要になるまで追加しない

## 完了条件

- 複数の時代区分を背景へ重ねて表示できる
- 全検証成功
