# Phase L18後UI最適化（完了）

優先度：L19開始前の保守

## 実装

- 「他プロジェクトと比較」をプロジェクト見出しの「管理メニュー」横へ移動し、タイムラインの縦表示領域を拡大する
- 配置設定の「タイムライン種別でグループ化」を「グループ化」へ短縮する
- 右下の丸型タイムライン操作ランチャーを廃止し、上部ツールバーを折り返さない一行へまとめる
- ズームと全体表示を「アイテムを追加」と表示モードの間へ配置し、表示密度と期間強調を「表示」メニューへ統合する
- ズームを従来の6段階から11段階へ増やし、既存の初期ズーム設定の意味を維持する
- 年月日の目盛りラベルを、表示幅から求めた間隔で衝突しない範囲まで増やす
- 期間強調を1本のバーと左右2つのつまみで指定する
- PCとスマートフォンの左ナビゲーション下部から `/help` へ移動できるようにする
- `/help` 配下へ主要機能別の静的ヘルプページを追加する

## データと容量

- DB、RLS、API、保存形式は変更しない
- ヘルプ本文はアプリのソースとして保持し、Supabase容量を使用しない
- 動的な機能別ヘルプルートは `generateStaticParams` と `dynamicParams = false` でビルド時生成する

## 完了条件

- 比較ボタンとタイムライン操作群の移動後も、通常表示と比較表示の操作が維持される
- ズーム、目盛り、二点レンジの単体・E2E回帰テストが成功する
- 全ヘルプページが静的生成され、左ナビゲーションから到達できる
- 共有ローカルDBを使う統合テストはファイル単位で直列実行し、テスト間の応答競合を防ぐ
- 全検証成功
