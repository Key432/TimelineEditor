# Phase L8.1：クラウド自動保存

優先度：P0

状態：完了（ローカル優先のクラウド同期、端末間復元、競合解決、保持期限）

## 依存

- Phase L8

## 実装

- IndexedDBへの保存後、同じ作業下書きをクラウドへデバウンス保存
- プロジェクト、対象種別、対象IDごとに1行だけを上書き
- 別端末ではクラウド下書きを取得し、IndexedDBへ復元
- オフライン時はIndexedDBへの保存を継続し、オンライン復帰後に同期
- 下書き専用世代番号による端末間の楽観的ロック
- 競合時にクラウド版または現在の端末版を選択するUI
- 「変更を保存」による確定成功後、ローカルとクラウドの作業下書きを削除
- 所有者限定RLS、認証済みロールへの最小権限、入力サイズ制約
- 30日更新されていない作業下書きをSupabase Cronで削除

## 保存境界

- `cloud_drafts` は復旧用の可変な作業下書きであり、版管理の対象にしない
- タイムラインアイテムとイベントアイテムの確定データは明示保存時だけ更新する
- 変更履歴は明示保存で確定した差分だけを記録する

## 容量最適化

- 入力回数にかかわらず、1編集対象につきクラウド下書きは最大1行
- 同一内容はローカル、クラウドとも重複保存しない
- 1下書きのJSON payloadを1MiB以下に制限
- 明示保存時の削除と30日の保持期限を併用

## 完了条件

- 別端末で未確定下書きを復元できる
- オフライン編集を失わず、復帰後に同期できる
- 競合で一方の入力を黙って上書きしない
- 自動保存では確定データと変更履歴を更新しない
- 所有者以外と匿名利用者はクラウド下書きを読み書きできない
- 全検証成功
