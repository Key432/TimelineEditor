# 検索・公開・入出力

## 18. タイムライン内フィルター・検索

現在のプロジェクト内に限定する。

### 18.1 フリーワード対象

- タイムラインアイテム名
- 本文
- イベントアイテムのタイトル
- イベントアイテム本文
- 出典
- 対象種別名

### 18.2 絞り込み条件

- 対象種別（複数）
- 表示年代の開始・終了
- イベントアイテムの有無
- 開始日が曖昧
- 終了日が曖昧
- いずれかの日付が曖昧
- 個別色の有無
- 表示・非表示状態

### 18.3 表示方法

- 一致する項目だけ表示
- 一致しない項目を薄く表示

イベントアイテムのみ一致した場合：

- 親行を残す
- 一致したマーカーをSecondary色のリング等で強調

### 18.4 URL状態

フィルター、並び順、グループ表示等をURLクエリへ反映する。フリーワード入力はIME変換中の値でURLを書き換えず、変換確定後に反映する。フィルターサイドパネルの背景オーバーレイはぼかさず、元のタイムラインとの位置関係を維持する。

例：

```text
/projects/abc/timeline
?q=漱石
&types=person,magazine
&from=1860
&to=1930
&hasEvents=true
&approximate=any
&filterMode=dim
&layout=compact
&sort=startDate
&direction=asc
&groupBy=itemType
```

フリーワード検索はタイムラインの描画用一覧へ本文を同梱せず、PGroonga検索から
一致したタイムラインアイテムIDとイベントアイテムIDだけを取得する。入力中は
短時間待ってから検索し、イベントだけが一致した場合は親を表示対象として残す。
非一致項目の薄表示は行表示とコンパクトレーン表示の両方へ適用する。

## 19. 全体検索

### 19.1 UI

- ヘッダーへ全体検索窓を常設
- 入力候補はデバウンス
- Enterで検索結果ページ
- 候補クリックで詳細ページへ遷移

### 19.2 対象

- プロジェクト名・説明
- タイムラインアイテム名・本文
- イベントアイテムのタイトル・本文
- 出典
- 外部URL表示情報
- 対象種別名

### 19.3 検索結果

種類ごとに表示：

- プロジェクト
- タイムラインアイテム
- イベントアイテム

表示項目：

- 種類
- タイトル
- 所属プロジェクト
- 一致箇所周辺の抜粋
- 日付または期間
- 詳細URL

ページネーションを実装する。

ヘッダー候補は300msのデバウンス後に最大6件を表示する。検索結果ページは
1ページ12件とし、全種類またはプロジェクト、タイムラインアイテム、イベント
アイテムの種類ごとに絞り込める。抜粋はHTMLとして解釈せず、一致語周辺の
プレーンテキストを表示する。

候補および検索結果のタイムラインアイテム・イベントアイテムへのリンクには、現在の検索結果URLを安全な `returnTo` として付与する。詳細ページから戻った際は検索語、種類フィルター、ページ番号を復元する。ブラウザ履歴が存在しない場合でもパンくずの「検索結果」から同じ状態へ戻れるようにする。

## 20. 公開・共有

### 20.1 公開ページ

- 認証不要
- 閲覧専用
- タイムラインのパン、ズーム、フィルター、詳細閲覧は利用可能
- 管理ナビ、編集パネル、登録・削除機能は非表示
- 公開プロジェクト一覧ページは提供しない
- `/public` 配下は600秒のISRとし、公開中プロジェクトのデータや設定を明示保存したときは対象公開ページ階層をオンデマンド再検証する。非公開化後の旧キャッシュを認可に使用せず、Proxyで公開状態を軽量に確認して即時404とする

### 20.2 publicId

- 初回公開時に推測困難なランダム値を生成
- 非公開へ戻しても維持
- 再公開時は同じURL
- 設定画面から共有URLを再発行可能
- 再発行後は古いURLを即時無効化

### 20.3 noindex

アプリ全体で以下を適用：

- `noindex`
- `nofollow`
- `noarchive`
- `nosnippet`
- `noimageindex`
- `X-Robots-Tag`
- `robots.txt`でクロール抑制
- sitemapを生成しない
- 公開ページへの公開ポータルを作らない

`noindex`はアクセス制御ではないことを公開確認画面へ明記する。

## 21. JSON・CSV入出力

### 21.0 データ互換性

- 現行DB、JSON、CSVをアプリケーションスキーマバージョン6とする。v1はL0基準、v2はL1歴史日付、v3はL6内部リンク・別名、v4はL9分類・カスタムフィールド、v5はL10イベント複数親モデル、v6はL12年代背景レイヤーとする
- DBの基準は `private.application_schema_versions` で記録し、アプリ利用者からは参照・更新できない
- JSONはルートの `schemaVersion`、CSVは各ファイルの先頭行とZIP内の `manifest.json` にスキーマバージョンを明示する
- バージョン指定のない旧JSON・旧CSVはバージョン0として読み込み、バージョン別移行処理を順番に適用してから現行スキーマで検証する
- 現行版より新しい未知のバージョン、版が不正または混在するCSVは保存前に拒否する
- タイムラインアイテムとイベントアイテムは `{ type, id }` の共通参照型を用いる
- 削除済み、存在しない、権限外の参照は利用者向けに同じ「参照先を表示できません」として扱い、非公開データの存在を漏らさない
- 後続機能は既定無効のFeature Flagで段階導入できる。未知のフラグ名は設定誤りとして拒否する
- 履歴、ゴミ箱、公開複製データは共通の保持上限方針を使用する。履歴は10日、1エンティティ10版、1プロジェクト25MB、ゴミ箱は5日とし、これらの上限や使用量をアプリ画面へ表示しない。公開版は現行版と過去最大1世代とする

### 21.1 JSON

完全バックアップ用。

含める：

- プロジェクト
- 設定
- 対象種別
- タイムラインアイテム
- イベントアイテム
- 年代背景レイヤーと背景期間
- 手動順
- 表示設定
- スキーマバージョン
- アプリバージョン
- エクスポート日時

`/projects/new` ではJSONから新しい非公開プロジェクトを作成する。既存プロジェクトのインポート画面とタイムライン上部の「インポート／エクスポート」では、確認後に現在のプロジェクト情報・設定・対象種別・タイムラインアイテム・イベントアイテムを上書きする。

JSONエクスポートのファイル名は `[project name]_YYYY-MM-DD.json` とする。

### 21.2 CSV

ZIP出力：

```text
[project name]_YYYY-MM-DD.zip
├─ manifest.json
├─ timeline-items.csv
├─ timeline-events.csv
├─ item-types.csv
├─ classification.json
├─ background-layers.json
└─ README.md
```

- UTF-8 BOM付き
- Excelでの編集を想定
- ID空欄は新規ID生成
- イベントアイテムの親指定はID優先、空欄時はタイトル照合
- イベントは1行だけ出力し、順序付きの親ID配列 `timeline_item_ids_json` と親タイトル配列 `timeline_item_titles_json` を使用する
- タイムラインアイテムの対象種別はID優先、空欄時は対象種別名照合
- `timeline-items.csv` の `type_id` が空で、`type_name` が既存対象種別にない場合は、その名前、Primary Color、末尾のソート順で対象種別を新規作成する
- タイトル照合は同名が複数ならエラー
- `item-types.csv`、`timeline-items.csv`、`timeline-events.csv` は単体でもインポートできる。その他のCSVファイル名は拒否する

### 21.3 インポート

- サーバー側で検証
- 保存前プレビュー
- エラー・警告一覧
- ID空欄で新規作成するタイムライン項目と、自動作成する対象種別は、それぞれ件数を集約して警告へ表示する
- 正常行のみ取り込み、または全体中止を選択
- 確定時はトランザクション
- 中途半端な登録を残さない
- `/projects/new` のCSV ZIPインポートは新規プロジェクトを作成する
- 既存プロジェクトへのCSV／CSV ZIPインポートは、ID一致行を更新し、未一致行を追加する
- L11の任意CSV取込は列名を固定せず、タイムライン表／イベント表の項目へ列または固定値をマッピングする。日付は年月日別列、ISO風表記、日本語年月日表記を選択できる
- マッピング設定だけを所有者用DBへ保存し、原CSVとプレビュー行はブラウザ内の一時データとして扱う
- 正常行だけを登録でき、重複候補と行別エラーを表示し、エラー行だけをUTF-8 BOM付きCSVとして再出力できる
- 選択行の簡易CSVは完全バックアップ用CSV ZIPとは別形式であり、アプリケーションスキーマv6を変更しない
