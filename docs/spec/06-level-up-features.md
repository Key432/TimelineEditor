# レベルアップ機能・完了条件

## 28. 閲覧操作・保存済みビュー

- タイムライン領域のアプリ内最大化と、対応ブラウザでのFullscreen APIを提供する
- 最大化／Fullscreen中も通常表示と同じ背景色を使い、メニュー、ポップアップ、モーダルを操作できる
- マウスポインター位置へ垂直年代線を表示し、重なるイベント・クラスターを強調する
- 縮尺、表示単位、全体に合わせる、行密度、期間強調の操作群はタイムラインフィールド右下へフロート表示する。既定は丸型の設定アイコンだけを表示し、クリックまたはキーボード操作で操作群を展開する
- 期間強調は初期状態を非表示とし、タイムラインフィールド内へフロート表示して表示／非表示を切り替えられる。始点と終点を指定し、選択期間を着色して期間外をグレーアウトする。期間レイヤーは時間軸部分だけへ描画し、固定情報列と編集操作列を覆わない。全期間ミニマップは実装を保留する
- 年代ジャンプ、表示位置ブックマークを提供する
- 表示年代、ズーム、スクロール、フィルター、並び順、グループ、レイアウト、背景、関係線、表示列を保存済みビューとして保存する
- 保存済みビューは設定JSONだけを持ち、データ本体や描画結果を複製しない

## 29. 履歴・復元

- タイムラインアイテムとイベントアイテムは、明示保存ごとに実際に変わったフィールドの変更前・変更後だけを差分履歴として保存する
- 本文等の複数行テキストは削除行と追加行を区別するGitHub風の差分表示とし、特定版への復元、手動チェックポイントを提供する
- 入力途中や並べ替えだけでは履歴を作らず、完全自動保存を導入するPhaseでは保存確定単位へ統合する
- 将来の一括操作は同一トランザクションの操作単位で履歴化し、Undoできる共通基盤を利用する
- 履歴は10日、1エンティティ10版、1プロジェクト25MBを固定上限とし、画面へ保持条件や容量を表示せず古い履歴から自動整理する
- ゴミ箱は5日保持し、`pg_cron`の日次処理で期限切れデータを完全削除する。無制限履歴と長期スナップショットはWeb版で提供しない
- 削除確認には内部リンクの参照件数とリンク切れになる旨だけを表示し、その他の依存関係やJSONバックアップ作成導線は表示しない

### 29.1 自動保存

- 入力中の下書きはまずIndexedDBへ保存し、オンライン時は所有者専用のクラウド作業下書きへ同期する
- クラウド作業下書きは対象ごとに1行を上書きし、確定データや変更履歴を自動更新しない
- 別端末から復元でき、競合時はクラウド版と端末版を利用者が選択する
- 明示保存後に作業下書きを削除し、放置されたクラウド下書きは30日で自動削除する
- クラウド作業下書きは1件1MiB以下とし、同一内容を重複保存しない

## 30. 内部リンク・別名

- 本文で `[[` を入力すると同一プロジェクト内の候補を表示する
- 選択後は `[[item:UUID|表示名]]` または `[[event:UUID|表示名]]` へ正規化し、名称ではなくIDで解決する
- 同名候補には種類、日付、親を表示し、名称だけで自動確定しない
- 名称変更後もリンクを維持し、削除済み参照は本文を残してリンク切れとして表示する
- 内部リンクを含むMarkdownは、参照解決中に内部記法を一瞬表示せず、解決後の本文をまとめて描画する
- 権限外と不存在を外部利用者から区別できないようにする
- 正式名称、原語名、旧名、筆名等の別名を複数登録し、検索、候補、重複検出に使用する
- 別名は任意項目として入力欄を既定で折りたたみ、設定件数を見出しに表示する
- Markdown記法ヘルプには候補の識別情報、名称変更時のリンク維持、リンク切れ表示を記載する
- プロジェクト複製・インポートでは内部ID参照を一括変換する

## 31. 分類・カスタムフィールド

- タイムラインアイテムとイベントアイテム共通のタグマスタを持ち、名称変更、統合、未使用削除、AND／OR検索を提供する
- イベント専用の種別マスタを持ち、形状・アイコンでも区別して色だけに依存しない
- タグ入力は選択済みチップ、検索・作成候補、候補ごとの「…」設定変更を備えるNotionのマルチセレクト相当とし、候補から名称・色・説明を編集できる
- イベント種別のマーカー形状は図形そのものを並べて選択する。単一種別のマーカーと同種別クラスターには設定した形状・色を使い、複数種別を含むクラスターは灰色の円で表示する
- プロジェクトまたはタイムライン種別ごとにカスタムフィールドを定義する
- 型は文字列、複数行、数値、真偽値、単一選択、複数選択、URL、歴史日付、他アイテム参照を扱う
- 定義と値を分離し、空値は保存しない。検索対象すべてへ無条件の汎用GINインデックスを作らない
- JSON／CSV ZIPのスキーマv4でタグ、イベント種別、カスタムフィールド定義・値と参照IDを追加し、v5でイベントの順序付き複数親、v6で年代背景レイヤー、v7で意味的関係を追加する。旧v0〜v6は段階移行する

## 32. テーブルビュー・一括操作・汎用CSV

- 「行表示／コンパクト」の表示モード切替へ「テーブル」を追加し、テーブル内でタイムライン表とイベント表を切り替える
- Notionを参考に、列表示、列幅、左から指定数の固定列、横スクロール、列ごとの折り返し、仮想スクロール、セル直接編集に対応する
- セル編集はフォーカスが外れた時点で確認なしに保存し、競合時は保存せずエラーを表示する。外部URLは安全なリンクとして表示する
- 本文と出典は表へ表示せず、名称列の「開く」から既存の詳細ページを表示する
- 時点型の時点日は「開始・時点日」列へ表示し、終了日と終了状態は編集不可にする
- 行追加は未保存行として開始し、名称、開始・時点日、期間型の終了状態（終了日指定時は終了日）、種別が揃うまでDBおよびタイムラインへ追加しない
- 列追加はプロジェクト共通の新しいカスタムフィールド定義を作成する
- 行追加、複数行選択、矢印キー移動、Enter編集、クリップボードのコピー・貼り付けを提供する
- タグ、対象種別、イベント種別、親、表示状態、個別色、カスタムフィールドを一括変更できる
- 複数削除の前に依存関係と参照件数を表示する
- 一括操作は逆パッチを1操作1行へ圧縮して保存し、直前操作をUndoできる。設定と逆パッチは所有者RLSで保護する
- 任意CSVの列マッピング、固定値、日付形式、設定保存、重複候補、エラー行再出力を提供する
- 選択行CSVは種別、タグ、親、当該行に接続する意味的関係を含めるか選択できる
- インポートファイルは恒久保存せず、プレビューは一時処理とする

## 33. 背景・品質・関係探索

### 33.1 年代背景レイヤー

- 時代区分、王朝、政権、文化潮流等を複数レイヤーとして重ねる
- レイヤーの表示、順序、色、説明、開始・終了、曖昧端点を管理する
- 行表示、コンパクトレーン、公開ページ、保存済みビューで利用できる
- 同一レイヤー内の期間重複を警告し、描画結果は保存しない
- JSONとCSV ZIPはレイヤーと期間を往復し、旧v0〜v5は背景なしとしてv6へ移行した後、意味的関係なしとしてv7へ移行する

### 33.2 データ品質・重複統合

- リンク切れ、削除済み参照、親なしイベント、全親の期間外イベント、必須情報不足、不正URL、未使用マスタ、孤立関係、Markdown問題を検出する
- 品質チェック一覧は同じアイテム・イベント・マスタを重複表示せず、検出理由を対象ごとの1行へまとめる。一覧件数は修正対象の件数とする
- 正規化タイトル、別名、日付、種別、親、URL、類似文字列から重複候補を提示する
- 統合前にプレビューし、イベント、タグ、内部リンク、関係、出典、カスタムフィールド、親を存続側IDへ付け替える
- 診断・類似度結果はオンデマンド生成または短時間キャッシュとし、恒久保存しない
- 公開状態だけを根拠とする「公開中だが未完成」の診断は行わない
- 品質診断と統計は同じオンデマンド分析データセットを参照し、統計用の複製データや長期スナップショットを作らない
- 統合Undoは10日、所有者あたり50操作、1操作5MiBを上限とする

### 33.3 関連ネットワーク

- アイテムとイベントをノード、意味的関係を方向付き／方向なしエッジとして表示する
- タグ、種別、年代、関係種別、期間強調、検索で絞り込む
- 直接関係と2段階関係を強調し、ノードから詳細を開く
- Force-directedを初期配置とし、大規模データは段階展開・クラスタ化する
- 自動配置結果は原則保存せず、利用者が明示固定した位置だけを保存できる余地を持つ

## 34. 下書き・公開・出力

### 34.1 下書きと公開版

- 下書き、公開済み、未公開変更ありを区別する
- 公開前プレビュー、変更を公開、現行公開版へ戻す操作を提供する
- 公開日時と公開リビジョンを記録する
- 公開表示に必要なデータだけを保持し、過去公開版は少数世代に限定する

### 34.2 SVG・PNG・PDF

- 共通の出力描画モデルを作り、SVGを基本としてPNG・PDFへ展開する
- 現在の表示、期間強調、全範囲、任意年代範囲を出力できる
- レイアウト、フィルター、グループ、背景、関係線、タイトル、説明、凡例を反映する
- 用紙、向き、余白、1ページ縮小、複数ページ分割、日本語フォント、ページ境界を設定する
- 生成物をSupabaseへ保存せず、可能な場合はブラウザ生成、サーバー生成時は一時ファイルとして破棄する

## 35. 比較・統計

### 35.1 プロジェクト横断比較

- 所有プロジェクトと閲覧可能な公開プロジェクトを共通時間軸で表示する
- パン、ズーム、期間強調、プロジェクト表示、タグ・種別フィルターを共有する
- 比較画面は閲覧専用とし、条件は保存済みビューの設定JSONとして保存できる
- 比較用データは複製せず、プロジェクト単位・表示年代付近で段階取得する

### 35.2 統計

- アイテム、イベント、種別、タグ、年代、期間、曖昧日付、複数親、関係、内部リンク、不足情報を集計する
- KPI、棒、折れ線、ヒストグラム、ヒートマップ、表で表示する
- 期間強調・フィルターと連動し、集計結果から該当項目へ移動し、CSV出力できる
- 原則オンデマンド計算とし、必要な場合だけ短時間キャッシュする

## 36. ローカルモード・PWA

- 未ログインでもIndexedDBへローカルプロジェクトを作成・自動保存できる
- IndexedDBスキーママイグレーション、ローカル全文検索、JSON・CSV入出力、容量不足警告を提供する
- PWAとしてインストールでき、オフライン閲覧・編集に対応する
- ログイン後に選択したプロジェクトだけをクラウドへ取り込む
- 取込時にID、内部リンク、複数親、関係を一括変換し、成功するまでローカルデータを削除しない
- ローカルデータは利用者の明示操作なしにSupabaseへ同期しない

## 37. Windowsネイティブ版

Windows版はWeb版の一機能ではなく独立製品とし、Web版のデータ形式が安定してから実装する。

- ローカルDB、自動更新、インストーラー、保存場所、バックアップを設計する
- 主要タイムライン、Markdown、リンク、タグ、カスタムフィールド、複数親、関係、テーブル、JSON・CSV、自動保存を提供する
- Windows版限定で複数画像、画像込みZIP、長期履歴、長期スナップショット、大規模統計キャッシュを扱える
- Web版との双方向取込、スキーマバージョン差異、未対応列の安全な無視を検証する
- Web互換CSVへ画像バイナリを含めず、画像は別マニフェストで管理する

## 38. Supabase無料枠の非機能要件

- Web版はSupabase無料枠の範囲で継続運用できる保存設計とする
- 容量は管理者がSupabase Dashboardで確認し、本アプリに容量監視API、診断UI、警告閾値、使用量通知を実装しない
- MarkdownとHTML、書誌情報、タグ名、比較データ等を不要に複製しない
- 履歴、ゴミ箱、クラウド作業下書き、公開版には保持制限を設け、古い自動データから整理する
- 画像、添付、生成ファイル、ネットワーク自動配置、統計スナップショットを恒久保存しない
- インデックスは制約と実際の検索に必要なものだけを追加し、容量を増やすPhaseで増加量を計測する
